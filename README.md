# Pass Key: аппаратный ввод паролей на RP2350-Touch-AMOLED-1.8

Плата [Waveshare RP2350-Touch-AMOLED-1.8](https://www.waveshare.com/wiki/RP2350-Touch-AMOLED-1.8) подключается
к компьютеру и определяется как обычная USB-клавиатура. На экране выбираете запись, нажимаете кнопку, и плата
сама набирает пароль в поле, где стоит курсор. Драйверы не нужны (macOS, Windows, Linux). Работает и в BIOS/UEFI,
и на экране входа FileVault: это boot-клавиатура.

## Возможности

- Список паролей, до 96 записей. В записи есть имя, логин, пароль и два флага: «Login + Tab» и «Enter в конце».
- Набор пароля одним касанием (кнопка ⌨ в строке списка). На экране записи можно отдельно набрать
  только логин или только пароль.
- Записи добавляются и редактируются прямо на плате: есть экранная клавиатура со всеми символами ASCII
  и генератор случайного пароля из 16 символов (аппаратный TRNG RP2350).
- PIN-код от 4 до 12 цифр. После 10 неверных PIN подряд все данные стираются. Счётчик хранится во flash,
  так что перезагрузка его не сбрасывает.
- Данные во flash зашифрованы. Через 5 минут бездействия плата сама блокируется.
- Через 30 секунд экран притухает, чтобы AMOLED не выгорал. Первое касание только будит экран и не нажимает
  кнопку под пальцем.
- Если на компьютере включён Caps Lock, плата это учитывает, и регистр букв в пароле остаётся правильным.
- Обновление прошивки через UF2 не стирает пароли.

## Как пользоваться

1. При первом включении задайте PIN и повторите его.
2. Нажмите **+ Add** и заполните Name, Login, Password. Кнопка 🔀 генерирует пароль, 👁 показывает его.
3. В списке нажмите ⌨ напротив записи: пароль будет набран в активное поле на компьютере.
   Нажатие на саму строку открывает карточку записи с кнопками **Type**, **Login**, **Password**, **Edit**
   и **Delete**.
4. Кнопка ⏻ в списке сразу блокирует плату. Кнопка ⚙ открывает настройки: яркость, смену PIN, полное стирание.

> **Раскладка.** USB-клавиатура передаёт коды клавиш, а не символы. Перед вводом переключите компьютер на
> английскую (US) раскладку, иначе при русской раскладке вместо `pass` наберётся `зфыы`.
> Интерфейс платы на английском: во встроенных шрифтах LVGL нет кириллицы.

На macOS при первом подключении может открыться «Ассистент настройки клавиатуры». Его можно просто закрыть.

## Сборка

Нужны Pico SDK 2.1+, `arm-none-eabi-gcc`, CMake и Ninja. Библиотеки платы (Waveshare и LVGL) по умолчанию
берутся из `../RP2350-Touch-AMOLED-1.8/lib`. Другой путь задаётся через `-DBOARD_LIB_DIR=...`.

```bash
export PICO_SDK_PATH=~/.pico-sdk/sdk
cmake -S . -B build -G Ninja -DPICO_TOOLCHAIN_PATH=~/.pico-sdk/toolchain
cmake --build build
```

Получится `build/pass_key.uf2`.

## Прошивка

1. Зажмите **BOOT** и подключите плату по USB (или зажмите BOOT и нажмите RESET).
2. Появится диск `RP2350`. Скопируйте на него `build/pass_key.uf2`.
3. Плата перезагрузится и появится в системе как клавиатура **Pass Key Keyboard**.

## Как устроено

```
ядро 0:  TinyUSB, HID-клавиатура: печатает очередь символов (нажатие/отпускание, 6 мс между отчётами)
ядро 1:  LVGL: экран SH8601 (QSPI через PIO) + тач FT3168 (I2C), хранилище паролей
```

- **Шифрование.** Из PIN и случайной соли (16 байт) PBKDF2-HMAC-SHA256 с 20 000 итераций выводит два
  ключа. Записи шифруются потоковым шифром HMAC-SHA256 в режиме счётчика, при каждом сохранении берётся
  новый nonce. Целостность проверяется по HMAC-SHA256, по нему же определяется неверный PIN.
  Ключ при разблокировке вычисляется около секунды.
- **Flash.** Хранилище занимает последние 36 КБ: сектор счётчика неверных PIN и два слота по 16 КБ.
  Запись идёт в более старый слот, а страница заголовка программируется последней. Если питание пропадёт
  посреди записи, останется предыдущая копия.
- Расшифрованные записи лежат только в RAM, пока плата разблокирована. При блокировке они затираются.
  Текст для набора стирается сразу после ввода. Если USB отключён или компьютер уснул, набор отменяется,
  и пароль не напечатается потом в случайное окно.

### Ограничения безопасности

Это удобный менеджер паролей, а не защищённый токен. В режиме BOOTSEL содержимое flash можно считать
(`picotool save`). Тогда короткий PIN подбирается перебором на компьютере, и счётчик попыток не помогает,
потому что он работает только на самой плате. Если плату могут унести, используйте длинный PIN (10–12 цифр).
Полностью эту дыру закрывает secure boot RP2350 с ключом в OTP, но это необратимая настройка чипа,
и в этой прошивке она не включена.

## Файлы

- `src/main.c`: запуск, USB-цикл на ядре 0
- `src/usb_kbd.*`, `src/usb_descriptors.c`, `src/tusb_config.h`: USB HID-клавиатура и набор текста
- `src/vault.*`: хранилище во flash, PIN, счётчик попыток
- `src/crypto.*`: SHA-256, HMAC, PBKDF2, потоковый шифр
- `src/ui.c`, `src/lv_conf.h`: интерфейс
