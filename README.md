# Pass Key: аппаратный ввод паролей на RP2350-Touch-AMOLED-1.8

Плата [Waveshare RP2350-Touch-AMOLED-1.8](https://www.waveshare.com/wiki/RP2350-Touch-AMOLED-1.8) подключается
к компьютеру и определяется как USB-клавиатура. На экране выбираете запись и нажимаете кнопку, а плата сама
набирает пароль в поле, где стоит курсор. Драйверы не нужны (macOS, Windows, Linux). Работает и в BIOS/UEFI,
и на экране входа FileVault: это boot-клавиатура.

Пароли добавляются и редактируются с компьютера, на странице `tools/passkey.html`. Вводить их на маленьком
экране не нужно.

## На плате

- **Список.** Крупные строки с названием и логином. Синяя кнопка ⌨ справа набирает запись одним касанием.
- **Карточка записи** (касание строки). Большая кнопка **Type** набирает запись целиком, кнопки **Login**
  и **Password** набирают их по отдельности, 👁 показывает пароль на экране.
- **Настройки** (⚙): яркость.
- Вверху два значка. Значок USB горит зелёным, когда плата подключена к компьютеру, ✎ горит, когда открыт редактор.
- Через 30 секунд экран притухает, чтобы AMOLED не выгорал. Первое касание только будит экран и не нажимает
  кнопку под пальцем.
- Если на компьютере включён Caps Lock, плата это учитывает, и регистр букв в пароле остаётся правильным.

## Редактор на компьютере

Откройте `tools/passkey.html` двойным щелчком в **Chrome**, **Edge**, Opera или Яндекс Браузере. Нужен
Web Serial, а его нет в Safari и Firefox. Интернет не нужен, страница работает как локальный файл.

1. Подключите плату и нажмите **Подключить плату**. В окне выберите **Pass Key Editor** (или порт
   `usbmodem…`). Дальше страница подключается сама, пока вы не закроете её.
2. **Новая запись:** название, логин, пароль. 🎲 генерирует случайный пароль заданной длины.
   Отметьте, что набирать: «Сначала логин + Tab» и «Enter в конце».
3. В таблице записей можно менять название, логин и флаги. Пароль меняется через поле «Новый пароль»;
   если оставить его пустым, старый пароль сохранится.
4. **Импорт из CSV:** экспорт паролей из Chrome, Edge, Firefox, Safari, Bitwarden или 1Password.
   Записи с тем же названием и логином пропускаются. После импорта удалите CSV-файл: в нём пароли открытым текстом.
5. Изменения сразу сохраняются во flash, и список на плате обновляется.

**Плата никогда не отдаёт пароли обратно на компьютер.** Редактор видит только названия, логины и длину
паролей, поэтому вредоносная программа на компьютере не может вытащить их через USB-порт.

> **Раскладка и символы.** USB-клавиатура передаёт коды клавиш, а не буквы. Перед вводом переключите компьютер
> на английскую (US) раскладку, иначе при русской вместо `pass` наберётся `зфыы`. По этой же причине в паролях,
> логинах и названиях разрешены только латиница, цифры и символы ASCII. Редактор подсветит недопустимые символы.

На macOS при первом подключении может открыться «Ассистент настройки клавиатуры». Его можно просто закрыть.

## Сборка

Нужны Pico SDK 2.1+, `arm-none-eabi-gcc`, CMake и Ninja. Библиотеки платы (Waveshare и LVGL) по умолчанию
берутся из `../RP2350-Touch-AMOLED-1.8/lib`. Другой путь задаётся через `-DBOARD_LIB_DIR=...`.

```bash
export PICO_SDK_PATH=~/.pico-sdk/sdk
cmake -S . -B build -G Ninja -DPICO_TOOLCHAIN_PATH=~/.pico-sdk/toolchain
cmake --build build
```

Получится `build/pass_key.uf2`.

## Прошивка

1. Зажмите **BOOT** и подключите плату по USB (или зажмите BOOT и нажмите RESET).
2. Появится диск `RP2350`. Скопируйте на него `build/pass_key.uf2`.
3. Плата перезагрузится и появится в системе как клавиатура **Pass Key Keyboard** плюс последовательный порт
   **Pass Key Editor**.

Обновление прошивки через UF2 пароли не стирает. Записи из версии с PIN (тег `pin-version` в git) эта версия
не читает: они были зашифрованы. Добавьте их заново через редактор.

## Как устроено

```
ядро 0:  TinyUSB: HID-клавиатура (печать по символам, 6 мс между отчётами)
         + CDC-порт для редактора (текстовый протокол, см. src/editor.h)
ядро 1:  LVGL: экран SH8601 (QSPI через PIO) + тач FT3168 (I2C), список паролей во flash
```

- Запросы редактора ядро 0 передаёт ядру 1 через почтовый ящик в общей памяти. Со списком и flash работает
  только ядро 1, поэтому синхронизация не нужна.
- **Flash.** Список лежит в последних 32 КБ, в двух слотах по 16 КБ с CRC32. Запись идёт в более старый слот,
  а страница заголовка программируется последней. Если питание пропадёт посреди записи, останется
  предыдущая копия.
- Текст для набора стирается сразу после ввода. Если USB отключили или компьютер уснул, набор отменяется,
  и пароль не напечатается потом в случайное окно.

### Безопасность

В этой версии нет PIN, и пароли во flash хранятся открытым текстом. Тот, у кого в руках плата, может набрать
любой пароль кнопкой или считать flash в режиме BOOTSEL (`picotool save`). Обращайтесь с платой как с
ключами от квартиры. Нужна защита PIN-кодом — соберите версию из тега `pin-version`.

## Файлы

- `src/main.c`: запуск, USB-цикл на ядре 0
- `src/usb_kbd.*`: HID-клавиатура и набор текста
- `src/editor.*`: протокол редактора поверх USB CDC
- `src/usb_descriptors.c`, `src/tusb_config.h`: составное USB-устройство (HID + CDC)
- `src/vault.*`: хранилище во flash
- `src/ui.c`, `src/lv_conf.h`: интерфейс на экране
- `tools/passkey.html`: редактор для браузера
